## Sobre mim

Trabalho na interseção entre **IA aplicada** e **engenharia de software** — construindo desde agentes autônomos com memória e uso de ferramentas até pipelines de automação que eliminam trabalho manual de verdade.

Confortável em todo o stack: consigo ir de um script de scraping em Python para uma API FastAPI e uma interface React no mesmo projeto. Mas onde realmente me concentro é em fazer LLMs funcionarem em contextos reais de produção — com RAG, memória, observabilidade e custo sob controle.

Não sou da turma que só faz `pip install langchain` e chama de produto.
